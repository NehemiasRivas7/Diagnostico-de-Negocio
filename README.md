## Descripción de los problemas

### Caso A: Predicción de abandono de clientes

El objetivo es identificar a los clientes con mayor probabilidad de abandonar el servicio. Esta información permite aplicar estrategias de retención de manera anticipada.

### Caso B: Predicción de ventas futuras

El objetivo es estimar los ingresos semanales de la empresa. Esta predicción permite mejorar las decisiones de presupuesto, inventario, marketing y precios.

## Instrucciones para ejecutar los notebooks

1. Abrir el proyecto.

2. Abrir el notebook correspondiente:

	Caso A: `caso_churn/churn.ipynb`

	Caso B: `caso_ventas/ventas.ipynb`

3. Seleccionar un entorno de Python con las dependencias instaladas y ejecutar las celdas en orden.
